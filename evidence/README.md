# Evidencias reales

Los scripts crean carpetas `dev/`, `qa/` y `prod/` con JSON de AWS, logs y PNG.
Estas carpetas se excluyen de Git porque contienen identificadores y registros de cuenta.
Las capturas para el PDF deben obtenerse del despliegue real; no usar imagenes simuladas como prueba de AWS.

Por entorno: `deployment.json`, `apply.log`, `demo-json.json`, `demo-multipart.json`,
`demo-presigned.json`, `demo-large.json`, imagenes originales y procesadas,
`aws-evidence.json`, capturas de consola, `destroy.log` y `destroy-verification.json`.
